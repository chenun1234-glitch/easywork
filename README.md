# EasyWork iOS beta: EasyTier relinking materials

This repository hosts release-specific materials for the EasyTier library used in EasyWork iOS TestFlight builds. Download the asset from **Releases** that matches the app version and build number.

The kit contains the matching EasyTier source, GNU LGPL/GPL license notices, application object code, and instructions to relink the app with a modified EasyTier library. A relinked app is **unsigned**. The original TestFlight signature cannot authorize it; installation requires your own eligible Apple signing identity and provisioning profile.

EasyTier upstream: https://github.com/EasyTier/EasyTier (LGPL-3.0). This repository is for license materials, not the TestFlight invitation or an alternate signed-app download.
